MO Recall PWA

To install as an Android app, deploy ALL files in this folder together on an HTTPS static host (such as GitHub Pages or Netlify). Open the deployed index.html URL in Chrome and use the browser menu > Add to Home screen / Install app. Open it online once before using offline.

Progress is saved automatically in browser localStorage after every rating or MCQ answer, and the question bank is stored on import. Closing and reopening days later retains progress as long as site data is preserved. Updates on the SAME HTTPS origin retain progress. A different URL, browser or device has separate storage. Clearing site data or uninstalling may erase it. Export Progress occasionally as a precaution.

Opening index.html directly from the ZIP or file:// will not install the PWA or enable its offline service worker. This package does not create a live public link or cloud sync.

Clinical content is educational and must be checked against current local guidelines.
